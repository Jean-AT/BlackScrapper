# BlackScrapper

BlackScrapper is a local-first MVP for collecting Blackboard UPC assignments and grades into a React dashboard backed by Firebase.

## Structure
- `scraper/` - Node.js + Puppeteer local scraper
- `web/` - React frontend
- `docs/` - project documentation

## Current status
The repository now contains the initial scaffold and documentation. The next step is wiring real Firestore persistence and the Blackboard extraction selectors.
